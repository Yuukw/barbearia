# 💄 Beleza Pro - Controle de Estoque

Sistema web para controle de estoque de uma loja de maquiagem.
Feito em **Java + JSP + Servlets + JDBC + MySQL**.

[Java](https://img.shields.io/badge/Java-17-orange)
[MySQL](https://img.shields.io/badge/MySQL-8.0-blue)
[Status](https://img.shields.io/badge/Status-Funcionando-green)

---

## ✨ Funcionalidades

- 🔐 Login com sessão - `admin / 1234`
- ➕ Cadastrar maquiagem
- 📋 Listar produtos em tabela
- ✏️ Editar produto
- 🗑️ Excluir produto com confirmação
- 🧮 Cálculo automático de subtotal e valor total do estoque
- 📄 Relatório com botão Imprimir / Salvar PDF
- 🚪 Logout

## 🛠️ Tecnologias

- Java 17
- JSP + JSTL
- Servlets
- JDBC
- MySQL
- HTML5 + CSS3 + Bootstrap
- Maven + Jetty 11.0.15
- Arquitetura MVC + DAO
